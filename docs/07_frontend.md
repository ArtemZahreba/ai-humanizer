# 7. Клієнтська частина

## 7.1. Технології
Frontend використовує HTML, CSS і JavaScript без окремого SPA-фреймворку. Шаблони рендеряться Flask/Jinja.

## 7.2. Файли

| Файл | Призначення |
|---|---|
| `templates/base.html` | Базовий HTML, підключення CSS/JS |
| `templates/index.html` | Основний інтерфейс |
| `static/css/style.css` | Стилі, теми, адаптивність |
| `static/js/client.js` | Генерація та отримання UUID клієнта |
| `static/js/main.js` | Навігація, тема, очищення, копіювання |
| `static/js/humanization.js` | Завантаження моделей/промптів і гуманізація |
| `static/js/prompts.js` | Відображення та CRUD промптів |
| `static/js/history.js` | Завантаження, відображення та пошук історії |

## 7.3. Розділи
### Humanization
Містить вибір моделі й промпту, поле введення з `maxlength="5000"`, лічильник символів, область результату, кнопки очищення, копіювання та запуску.

### Prompts
Відображає стандартні й користувацькі промпти. Фільтри: All Prompts, Standard, My Prompts. Для власних промптів доступні перегляд, редагування та видалення через модальне вікно.

### History
Відображає модель, назву промпту, дату, початковий текст і результат. Пошук виконується у браузері серед уже завантажених записів.

## 7.4. Ідентифікатор клієнта
`client.js` читає `ai_humanizer_client_id` з `localStorage`. Якщо його немає, генерує UUID через `crypto.randomUUID()` і зберігає його. Значення передається до API для операцій з промптами й історією.

## 7.5. Теми
Тема встановлюється через атрибут `data-theme` на `html` та CSS custom properties. Вибір зберігається в `localStorage` під ключем `ai-humanizer-theme`.

## 7.6. Адаптивність
У CSS використовуються Grid, Flexbox та media queries. На вузьких екранах навігація переходить у горизонтальне розташування, а редактори й блоки порівняння історії — в одну колонку.
